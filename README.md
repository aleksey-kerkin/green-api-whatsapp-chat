# WhatsApp Chat (Green API)

Веб-приложение для переписки в WhatsApp через инстанс [GREEN-API](https://green-api.com/). Сообщения только текстовые. Отдельный сервер не нужен: страница в браузере сама обращается к GREEN-API.

Готовая версия: https://aleksey-kerkin.github.io/green-api-whatsapp-chat/

## Что понадобится

- [Node.js](https://nodejs.org/) 22. Проверка: `node -v`.
- Инстанс WhatsApp в личном кабинете GREEN-API и два значения с его страницы: `idInstance` и `apiTokenInstance`.

Адрес API вводить не нужно. Приложение всегда использует `https://api.green-api.com`.

## Локальный запуск

В папке проекта:

```bash
npm install
npm run dev
```

Откройте в браузере адрес, который Vite напечатает в терминале. Обычно это http://localhost:5173/.

Остановить сервер: `Ctrl+C` в том же терминале.

## Как пользоваться

1. На экране входа введите `idInstance` и `apiTokenInstance`, затем нажмите **Войти**.
2. Если сверху написано «Очередь HTTP API выключена», нажмите **Включить получение**. Без этого ответы собеседника в чат не придут.
3. Нажмите **Новый чат**, введите номер телефона с кодом страны и нажмите **Создать чат**. Подойдёт номер из 10–15 цифр, например `79001234567`. Восьмёрку в начале российского номера можно оставить: `89001234567` будет принят как `79001234567`.
4. Напишите сообщение внизу и нажмите **Enter** или кнопку отправки. **Shift+Enter** переносит строку, не отправляя текст. Длиннее 20000 символов сообщение не уйдёт.
5. У своего сообщения справа виден статус: «ожидает», «отправлено», «доставлено», «прочитано» или «ошибка». При ошибке под сообщением есть кнопка **Повторить**.
6. Ответ собеседника появляется в той же ленте. На узком экране список чатов и открытый чат показываются по очереди; кнопка **Назад** возвращает к списку.
7. **Выйти** забывает только данные входа. Переписка остаётся в этом браузере и снова появится после входа в тот же инстанс.

`idInstance`, токен и переписка хранятся в браузере (`localStorage`) и в репозиторий не попадают.

## Тесты и сборка

```bash
npm test
npm run build
```

`npm test` проверяет приложение без обращений к GREEN-API. `npm run build` собирает страницу в папку `dist`.
